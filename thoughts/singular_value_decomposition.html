The Singular Value Decomposition

I am reviewing the properties and subtleties of this decomposition. So why no write about them while I do!

The singular value decomposition (SVD) always exist for any matrix of size N by M (the matrix can be any size in general). The SVD breaks a matrix into the matrix product of three other matrices: the matrix of left singular vectors, the singular vector matrix, and the right singular vectors. Each have a clear geometric interpretation, which I shall elaborate.

Basics

The left singular vectors U is of size N by N. The matrix is unitary, meaning that its transpose is its inverse: UUT=UTU=I. The matrix can be complex in general. It is unique, up to a column-wise phase shift. When real, the matrix columns are unique up to the sign.

The singular values S is of size N by M. The matrix is zero everywhere, except along the main diagonal, which is composed of non-negative, real singular values. The values along the diagonals are usually sorted in descending order. This choice renders the singular value matrix unique.

The right singular vectors V is of size M by M. The matrix is unitary, meaning that its transpose is its inverse: VVT=VTV=I. The matrix can be complex in general. It is unique, up to a column-wise phase shift. When real, the matrix columns are unique up to the sign.

The SVD of an N by M matrix G will be denotes mathematically as G=USVT

Properties

The general solution to any linear system can be decomposed into two portions: the solution to the original linear system and any solutions to the homogeneous linear system. These two portions will be referred to as the particular part and the null part respectively. It turns out that the SVD cleanly divides the operator of any linear system into parts that act on the particular and null vectors spaces associated with the arguments of the linear system.

Singular values can be zero. The situation is that the singular value will annihilate the associated right singular vector (a column vector of the right singular vectors). In other words, the associated right singular vector lives in the null space of the operator. The number of zero singular vectors is indicative of the dimension of the null space of the operator. The number of non-zero singular values indicate the rank of the operator; this is just the rank-nullity theorem dressed up in SVD clothing.

What we can deduce from the previous paragraph is that under-determined linear systems will always have zero singular values! In practice, usually the singular values will appear to be nearly zero — nearly zero is close enough. The interpretation of small singular values is that these directions are damped, or suppressed, by the operator.

We could say that in the forward problem that the operator has poor sensitivity to the small singular value directions. Two inputs that are close but different will produce nearly identical results after being scaled by a small number. So this should raise alarm bells for people interested in inverting these linear systems. These insensitive directions will be very sensitive to small changes when the SVD is inverted. Practically this manifests as instability.

The condition number of an operator is the ratio of the largest singular value over the smallest singular value. Large condition numbers are an indication that the linear system is ill-conditioned. In practice, this might look like conditions numbers greater than 10000. Although that number is kind of off-the-cuff.
